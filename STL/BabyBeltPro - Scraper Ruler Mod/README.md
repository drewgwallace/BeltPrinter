# BabyBeltPro - Scraper Ruler Mod

**WORK IN PROGRESS**

The idea is to add a metal edge to the scraper. A metal ruler (without the cork backing) is an inexpensive and effective option.

This ruler measures **0.7 mm thick** by **19 mm wide**.  
M3 screw holes have been added to lock the ruler in place (Caution: threads into plastic).
