# EM Flow Test Blocks

Two STL files are provided:  
- One designed for a **30° belt axis**  
- One designed for a **45° belt axis**

These blocks are intended for calibrating your printer’s **Extrusion Multiplier (EM) / Flow**.  
They allow you to evaluate extrusion accuracy under the actual belt angle your machine uses.

## Recommended Use

For best results, pair these test blocks with the **Repetition-based EM calibration method**:

[Repetition Guide](../ideaMaker/Repetition/README.md)

This enables automated, incremental EM changes between printed objects.

## Inspiration

These calibration blocks were inspired by the extrusion multiplier tuning concepts from:

https://ellis3dp.com/Print-Tuning-Guide/articles/extrusion_multiplier.html
